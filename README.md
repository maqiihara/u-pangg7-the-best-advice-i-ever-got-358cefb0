One sentence, up to 200 characters, on the best advice I ever received — a [make.fun](https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0) bounty entry. A judge model compares entries pairwise and the line that carries the most lived truth wins.

## The entry

> My first boss told me, 'Nobody remembers the extra hour you worked, but everyone remembers the promise you broke,' and I have treated every promise like a debt ever since.

A real moment (my first boss), a sharp contrast (the extra hour nobody remembers vs the broken promise everyone does), and a consequence I still live by.

## Run it

```sh
python3 -P -s main.py
```

Writes one sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`), standard library only.
